## Projetos

### [MetaScope VAL](https://github.com/JoaoGAlmeidaS/Meta-Scope-VAL) · [ver o site](https://joaogalmeidas.github.io/Meta-Scope-VAL/)

Análise estatística do competitivo de VALORANT, do dado bruto ao site.

- Site estático multipágina com Jinja2, CSS próprio com design tokens e gráficos interativos em ECharts: rankings, páginas de time com busca e filtros por período e circuito.
- Pipeline de dados com contrato Pydantic, warehouse em dbt sobre DuckDB e orquestração com Dagster.
- Todo número publicado tem intervalo de confiança.
- CI com GitHub Actions: lint, testes e build completo a cada push, com publicação semanal no GitHub Pages.

### [Emityma](https://github.com/JoaoGAlmeidaS/Emityma) · [ver a demonstração](https://joaogalmeidas.github.io/Emityma/)

Plataforma web de gestão de propriedades rurais, feita em projeto acadêmico.

- Django, com cadastro e login (senhas com hash) e permissões por fazenda em três níveis.
- Painel com indicadores de produção e gráficos em Chart.js, com interface em Bootstrap.
- Testes, build estático e deploy da demonstração no GitHub Pages pelo GitHub Actions.

### Software de gestão para psicólogos com IA *(repositório privado)*

Aplicação de gestão de consultório para Windows: pacientes, prontuário, agenda, financeiro e backup.

- Interface em HTML, CSS e JavaScript, back-end em Python e banco SQLite criptografado.
- Contas com Supabase (Auth e PostgreSQL) atrás de uma API em n8n, com login offline por assinatura digital.
- Plano com IA pensado para a LGPD: a transcrição de áudio e a censura de dados pessoais rodam no computador do psicólogo, e só o texto já censurado vai para o Gemini.
